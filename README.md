# zcode-plugins

ZCode 插件市场仓库：根目录 `marketplace.json` 为市场清单，每个子目录一个插件。使用方在 ZCode「插件市场 → 添加」粘贴本仓库 URL 即可安装。

## 新增技能的硬性约定

- **原则一节必须有**：每个 SKILL.md 在开头附近带 `## 原则：先思考，后对照`——本技能不替代大模型的原生思考，只固定产物契约 / 盲区核对 / 人工闸门三件事；模板是最低要求不是思考边界。
- **技能自描述**：不引用插件级叙事（如"XX 工作流第 N 步"），为未来新工作流留位。
- **项目无关**：项目规范一律引用"当前仓库 AGENTS.md / 工程惯例（如有）"，不硬编码具体项目细节。
- **简洁**：只留承重内容（停止点、证据要求、契约、盲区核对），删过程叙述。

## 发版

修改插件后：同步升 `plugin.json` 与 `marketplace.json` 的版本号 → commit + push → 使用方在客户端刷新市场后更新插件。
